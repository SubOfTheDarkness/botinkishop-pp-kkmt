## О проекте

Botinki Shop — веб-приложение интернет-магазина обуви, разработанное в рамках производственной практики.

## Цель и задача

Цель работы — закрепление практических навыков разработки программного обеспечения.

- Задание 2. Алгоритм и приложение «Каталог обуви».
- Задание 3. Последовательный пользовательский интерфейс и оформление заказа: авторизация, навигация, обработка исключений, сортировка, фильтрация, поиск, карточка товара и оформление заказа.

## Основные возможности

- Просмотр каталога обуви и карточек товаров.
- Поиск, фильтрация и сортировка товаров.
- Просмотр доступных размеров и остатков.
- Регистрация и авторизация пользователей.
- Добавление товаров в корзину.
- Оформление заказов и просмотр истории покупок.
- Административная панель для управления товарами, пользователями и заказами.
- Автоматический расчёт скидок.

## Запуск приложения

1. Установить Python.
2. Установить необходимые зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Инициализировать базу данных:

   ```bash
   flask --app app init-db
   ```

   **Внимание:** инициализация создаёт таблицы базы данных и очищает прежние данные.

4. Запустить приложение:

   ```bash
   python run.py
   ```

5. Открыть в браузере адрес:

   `http://127.0.0.1:5000`

## Использование

Пользователь может зарегистрироваться или войти в аккаунт, выбрать товары в каталоге, указать нужный размер и количество пар, добавить их в корзину и оформить заказ.

Администратор получает доступ к административной панели, где может управлять товарами, пользователями и заказами.
